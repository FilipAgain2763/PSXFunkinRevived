# PSXFunkin - Revival
Friday Night Funkin' on the PS1.

## Note
I do not know/understand any bit of PS1 code whatsoever, so this is new territory for me. Don't go at me for not making things work the first time.

## Installation
Install the latest version from the Releases tab for your device, whether it's PS1, PSP/PSVita or 3DS. (Note that no releases of PSXFunkin Revival are out yet!)

## Compilation
Refer to [COMPILE.md](/COMPILE.md) for compilation instructions.
